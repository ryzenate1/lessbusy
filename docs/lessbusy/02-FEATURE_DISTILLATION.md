# LessBusy feature distillation

Updated 18 October 2026. This records source implementation, not an installed or verified product. The user explicitly deferred tests, builds, runtime execution, schema installation and production work for this experimental pass. Existing CRM capabilities and earlier LessBusy changes remain in place.

| Area | Decision | Implemented in source | Work still open |
|---|---|---|---|

| Deals | KEEP / SIMPLIFY | Metadata-driven pipeline board, search, stage/owner filters, real amounts and close dates, confirmed updates with concurrency checks, notes and customer links | Further board interaction polish; native drag/drop, saved views and advanced controls remain available |
